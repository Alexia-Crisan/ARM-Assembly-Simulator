Architecture Overview

32-bit ARM-inspired ISA. 16 general-purpose registers (R0–R15). R13 = SP (stack pointer), R14 = LR (link register), R15 = PC (program counter).

Unified memory — single flat address space: instructions at 0x0000, data/stack at 0x0100 (default 512-byte total, configurable).

Condition flags: N (negative), Z (zero), C (carry), V (overflow). Updated only by CMP, TST, or when the S-bit is set.

Scratch registers: R12 is the primary assembler scratch (pseudo-instructions). R11 is used as a secondary scratch by ROL and ROR only. Avoid using R11/R12 as operands to those pseudo-instructions.

Data Processing Instructions

Encoding: cond | 00 | I | opcode(4) | S | Rn(4) | Rd(4) | operand2(12)
Mnemonic Syntax Operation Encoding note
MOV MOV Rd, #imm / Rm Rd = imm or Rm opcode 1101
ADD ADD Rd, Rn, Rm/#imm
ADD Rd, Rm/#imm		 Rd = Rn + op2
Rd = Rd + op2		 opcode 0100
SUB SUB Rd, Rn, Rm/#imm
SUB Rd, Rm/#imm		 Rd = Rn − op2
Rd = Rd − op2		 opcode 0010
RSB RSB Rd, Rn, Rm/#imm
RSB Rd, Rm/#imm		 Rd = op2 − Rn  (reverse subtract) opcode 0011
CMP CMP Rn, Rm/#imm Sets flags from Rn − op2. No result written. opcode 1010, S=1
TST TST Rn, Rm/#imm Sets flags from Rn & op2. No result written. opcode 1000, S=1
AND AND Rd, Rn, Rm/#imm Rd = Rn & op2 opcode 0000
ORR ORR Rd, Rn, Rm/#imm Rd = Rn | op2 opcode 1100
EOR EOR Rd, Rn, Rm/#imm Rd = Rn ^ op2 opcode 0001
BIC BIC Rd, Rn, Rm/#imm
BIC Rd, Rm/#imm		 Rd = Rn & ~op2  (bit clear) opcode 1110
MVN MVN Rd, Rm/#imm Rd = ~op2 opcode 1111
Immediate encoding: 12-bit field = rot(4) | imm8(8). Value = ROR(imm8, rot×2). Not all 32-bit constants are representable — the assembler raises an error if the value does not fit.

TST and CMP are flag-only: they always set S=1 and never write a destination register. RSB is the only instruction that can compute #imm − Rn in a single word (e.g. RSB R1, R0, #0 negates R0 into R1).

Multiply / Divide

Encoding: cond | 000000 | A | S | Rd(4) | 0000 | Rs(4) | 1001 | Rm(4)
Mnemonic Syntax Operation
MUL MUL Rd, Rm, Rs
MUL Rd, Rs		 Rd = Rm × Rs (integer, 32-bit result)
DIV DIV Rd, Rm, Rs
DIV Rd, Rs		 Rd = Rm ÷ Rs (integer division, truncated toward zero)
DIV by zero raises a runtime ZeroDivisionError and halts the simulation.

Load / Store

Encoding: cond | 01 | I | P | U | B | W | L | Rn(4) | Rd(4) | offset12(12)
Mnemonic Syntax Operation Notes
LDR LDR Rd, [Rn]
LDR Rd, [Rn, #off]		 Rd = mem32[Rn + off] B=0, L=1
STR STR Rd, [Rn]
STR Rd, [Rn, #off]		 mem32[Rn + off] = Rd B=0, L=0
LDRB LDRB Rd, [Rn]
LDRB Rd, [Rn, #off]		 Rd = mem8[Rn + off], zero-extended B=1, L=1
STRB STRB Rd, [Rn]
STRB Rd, [Rn, #off]		 mem8[Rn + off] = Rd[7:0] B=1, L=0
LDR/STR transfer 32 bits (word-aligned). LDRB/STRB transfer exactly 1 byte. LDRB zero-extends — bits 31:8 of the destination are always cleared. STRB writes only the lowest byte of the source register; the surrounding bytes in memory are untouched. Memory is big-endian. Access outside bounds raises MemoryError.

Stack Operations

Encoding: cond | 100 | P | U | S | W | L | Rn(4) | reg_list(16) — Base register = R13 (SP)
Mnemonic Syntax Operation
PSH / PUSH PSH {R0, R1, ...} SP -= 4 per register; writes registers to memory. Full-descending stack.
POP POP {R0, R1, ...} Reads registers from memory; SP += 4 per register.
SP (R13) starts at the top of the data region (empty-descending). First push writes to the last word of the data region.

Branch Instructions

Encoding: cond(4) | 101 | L | offset24(24) — Target = PC + 8 + offset×4
Mnemonic Condition Flags tested Notes
B Always — Unconditional jump
BEQ Equal Z=1
BNE Not equal Z=0
BLT Less than N≠V Signed
BGT Greater than Z=0 and N=V Signed
BGE Greater or equal N=V Signed
BLE Less or equal Z=1 or N≠V Signed
JMS Always (with link) — LR = PC+4, then jump. Use RET to return.
RET — — MOV PC, LR — returns from subroutine
ARM pipeline offset: when a branch executes, PC has already been fetched 8 bytes ahead, so target = PC + 8 + (offset × 4).

System Instructions

Encoding: 1111 | opcode(3) | operand(25) — identified by top nibble 0xF
Mnemonic Syntax Operation
HLT HLT Stop execution. Always place at end of program.
INP INP Rd Read integer from stdin → Rd (desktop / server mode only)
OUT OUT {R0, R1, ...} Print values of listed registers to stdout

Pseudo-Instructions

Step Debugger

The debugger lets you step through a program one instruction at a time, watching registers and memory change live.
Button Action
▲ Debug Assemble the program and enter debug mode. The editor becomes read-only and the debug toolbar appears.
Step → Execute one instruction. The current source line is highlighted in green. Changed registers are marked with a green dot.
Run » Run continuously at ~120 ms per step until the program halts or you press Stop.
✕ Stop Exit debug mode and return the editor to normal.
The current instruction is shown in the green banner at the top of the Visualization panel. The status bar below the editor shows the step count and current PC address. INP is not supported in the web debugger — pre-compute any inputs before debugging.

Condition Flags

Flag Name Set when…
N Negative Result bit 31 = 1 (result is negative in signed interpretation)
Z Zero Result == 0
C Carry ADD: unsigned overflow; SUB/CMP/RSB: no borrow (rn ≥ val2)
V Overflow Signed overflow occurred
S-bit rule: Flags are updated only when the S bit (bit 20) is set. CMP and TST always set S=1. Plain ADD/SUB/etc. have S=0 and leave flags unchanged.
